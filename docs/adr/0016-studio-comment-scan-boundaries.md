# ADR-0016 — Ограничить поиск новыми и целевыми карточками Studio

## Контекст

В большой ленте Studio повторная проверка просмотренных комментариев и раскрытие веток в нерелевантных карточках задерживают поиск и создают лишнюю нагрузку на Chromium. URL известной публикации можно использовать для сужения поиска. Большие наборы также требуют сократить обращения Playwright к отдельным элементам.

## Решение

При поиске публикации использовать известный post URL, обрабатывать между прокрутками только новые карточки и раскрывать ветки только в карточках целевой публикации. При полном сборе ленты каждую новую карточку обрабатывать не более одного раза за проход. В live Playwright получать ссылку и заголовок публикации вместе со всеми полями комментариев одним read-only DOM snapshot; synthetic IDs и время создавать в Python. Для старого Comment без `post_url` оставить ограниченный поиск по ленте, не перечитывая уже обработанные группы.

## Почему

Отклонено повторное чтение просмотренных комментариев и раскрытие ответов в нерелевантных карточках. Один DOM snapshot выбран вместо обращений Playwright к элементам по одному; fake DOM path сохраняется для тестов.

## Последствия

Во время прохода нужно различать новые и уже обработанные карточки. Поиск публикации не раскрывает чужие ветки, а полный сбор по-прежнему обрабатывает каждую новую карточку один раз. Старые записи без URL публикации используют ограниченный fallback.
