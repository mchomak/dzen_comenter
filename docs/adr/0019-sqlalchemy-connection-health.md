# ADR-0019 — Проверять соединения SQLAlchemy перед повторным использованием

## Контекст

После сбоя страницы или worker неактивное соединение PostgreSQL может стать непригодным. Worker и admin используют SQLAlchemy engines; повторное использование закрытого соединения может помешать сохранить статус.

## Решение

Настроить оба SQLAlchemy engine через общий factory с pre-ping и recycle соединений. Схему базы данных для этого поведения не менять.

## Почему

Выбранная настройка проверяет соединение перед повторным использованием и обновляет соединения в пуле. Повторно использовать закрытые idle соединения — это проблемный сценарий, который решение устраняет; изменение схемы для проверки соединений не требуется.

## Последствия

Настройки соединений worker и admin остаются согласованными через общий factory. Здоровье соединения проверяется при повторном использовании; миграция схемы не нужна.
