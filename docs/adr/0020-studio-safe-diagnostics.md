# ADR-0020 — Не включать содержимое комментариев в диагностику Studio

## Контекст

Для разбора ошибок сканирования, публикации и восстановления нужно различать этапы и причины. Для такой классификации не нужны содержимое комментариев и идентифицирующие детали.

## Решение

Логировать только безопасные phase/reason, timings, counts, число DOM attempts и необязательные данные JS heap. Не включать в диагностику авторов, тексты комментариев, ссылки, URL, tokens и HTML. Безопасными счётчиками различать исчерпание scan budget, изменившийся или отсутствующий control, ошибку публикации и зависший цикл.

## Почему

Явно исключено логирование авторов, текста комментариев, ссылок, URL, tokens и HTML. Указанные safe events и counters позволяют классифицировать ошибки без этих данных.

## Последствия

Диагностика показывает фазу, причину и агрегированные данные сканирования и восстановления, но не раскрывает текст комментария, автора, ссылку, URL, token или разметку страницы.
