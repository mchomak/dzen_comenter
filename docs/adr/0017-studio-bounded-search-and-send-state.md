# ADR-0017 — Отличать исчерпание поиска от подтверждённого отсутствия

## Контекст

Поиск исходного комментария может достичь лимита, не доказав, что комментарий удалён или отсутствует. Публиковать без исходного комментария нельзя. Если отправка началась, но её результат неизвестен, повторять её небезопасно.

## Решение

При исчерпании поиска записывать `scan_limit_reached=true` и `absence_confirmed=false`. Сохранять конечный лимит повторных попыток публикации. Не публиковать, если исходный комментарий не найден. Неопределённую отправку считать отдельным терминальным статусом и не повторять.

## Почему

Отклонено представлять исчерпание ограниченного поиска как подтверждённое отсутствие или удаление. Для неопределённой отправки отклонён повтор публикации, который мог бы создать дубль. Явные поля сохраняют различие между достигнутым лимитом и доказанным отсутствием.

## Последствия

Операторы и последующая логика различают неполный ограниченный поиск и подтверждённое отсутствие. Лимит повторных попыток остаётся конечным; неопределённая отправка не запускается автоматически снова.
