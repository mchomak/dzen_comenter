# Персонализация ответов и нативный CTA

## Цель

Сделать ответы бота адресными и убрать отдельную рекламную строку со ссылкой, которую Яндекс может считать спамом.

## Поведение ответа

- Для комментария с непустым `author` итоговый текст публикации имеет вид `<полное имя автора>, <ответ ИИ>`.
- Перед добавлением имени первая буква текста ИИ приводится к нижнему регистру. Символы до первой буквы (например, эмодзи) остаются без изменений.
- Если имя автора отсутствует, публикуется только ответ ИИ: без начальной запятой и пробела.
- Ограничение `max_reply_length` применяется к итоговому тексту, включая добавленный префикс автора.

## CTA

- Поле CTA в настройках принимает непустой произвольный текст, включая запись без протокола, например `domeo ru`.
- Поле в HTML использует тип `text`; серверная проверка URL удаляется.
- Текущий алгоритм отбора CTA-кандидата и интервал `cta_every_n_comments` сохраняются.
- Для сработавшего CTA-кандидата текст CTA передаётся ИИ в дополнительной инструкции.
- Инструкция требует органично встроить текст CTA в смысл ответа: не добавлять его отдельной строкой, не делать отдельным рекламным предложением и не использовать URL.
- Код больше не дописывает CTA после сгенерированного текста.

## Затрагиваемые компоненты

- `dzen_commenter/orchestrator/loop.py`: резервирование длины под имя, нормализация начала ИИ-текста, сборка финального ответа, CTA-инструкция вместо постфикса.
- `dzen_commenter/admin/validation.py` и шаблон настроек: произвольный текст в CTA-поле.
- Конфигурация промпта: правила органичной интеграции CTA.
- Тесты оркестратора, промпта и админки: новая форма ответа, ограничение длины, текстовый CTA и отсутствие программной приписки.

## Вне области

- Изменение частоты CTA, механизма определения CTA-кандидатов и исторических ответов.
- Гарантия того, как Яндекс классифицирует конкретный комментарий: изменение устраняет явную отдельную ссылку, но не может гарантировать решения внешней антиспам-системы.

## Проверка

- Автоматические тесты подтверждают формат `Имя, ответ` и строчную первую букву ИИ-текста.
- Автоматические тесты подтверждают, что `domeo ru` сохраняется через настройки.
- Автоматические тесты подтверждают, что CTA передаётся ИИ в инструкции и не дописывается программно отдельной строкой.
- Перед деплоем выполняется полный `pytest`.
