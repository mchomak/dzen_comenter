## Что должно заработать

В prompt передаётся вся короткая ветка, а у длинной — последние 400 символов: это наиболее свежие предыдущие сообщения, потому что адаптер Дзена накапливает ветку в хронологическом порядке. Сам комментарий, заголовок и article context не сокращаются этим таском.

## Из брифа, дословно

> «как можно еще сильнее оптимизировать затраты токенов у бота ?»

## Разделы спецификации

Истории 3–4 (R02.1 углубляет R02); Решения 3–4, 7; Шов «Конструктор prompt».

## Критерии приёмки

- [ ] Ветка длиной не более 400 символов передаётся без изменений.
- [ ] У более длинной ветки в prompt есть только последние 400 символов; начало не попадает, а окончание сохраняется байт-в-байт.
- [ ] Пустая ветка сохраняет существующее человекочитаемое значение «нет предыдущих сообщений».
- [ ] Сокращение не применяется к `comment_text`, `publication_title`, `post_url` или `article_text`.
- [ ] Тесты prompt проходят без внешних вызовов.
