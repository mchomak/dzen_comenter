## Что должно заработать

Появляется обезличенный воспроизводимый отчёт: SQL-агрегаты, результаты токенизатора текущей модели, формула экономии и вердикт каждой гипотезы. На сервере ничего не изменяется.

## Из брифа, дословно

> «придумай новые гепотезы и проверь их на деле»
> «можешь заходить на сервер и использовать реальные данные с БД, только ничего не удаляй»
> «в итоге напиши мне отчет по тому насколько удалось снизить затраты, какие гепотезы подтвердились а какие нет, используй api ключ от ИИ с сервера для тестирования»

## Разделы спецификации

Истории 1–2, 5–12; Решения 1–3, 5–6, 9–11.

## Критерии приёмки

- [ ] Все server-команды в отчёте классифицированы как read-only; нет secret values и пользовательских текстов.
- [ ] Есть численные базовые/кандидатные токены и метод подсчёта текущей моделью.
- [ ] Есть отдельный вердикт для подтверждённых, неподтверждённых и заблокированных балансом гипотез.
- [ ] Показана разница между измерением на выборке и будущим production-эффектом после deploy.
