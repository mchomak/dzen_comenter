## Что должно заработать

Почасовой лимит до вызова модели считает каждый уже сохранённый результат генерации независимо от того, опубликован он или остался черновиком. Это не позволяет режиму `auto_publish=false` обходить лимит и запускать неограниченные AI-вызовы.

## Из брифа, дословно

> «как можно еще сильнее оптимизировать затраты токенов у бота ?»

## Разделы спецификации

Истории 3–4; Решения 5–7; Швы «Репозиторий ответов» и «Цикл ответов».

## Критерии приёмки

- [ ] Репозиторий возвращает число сохранённых replies после заданного времени для статусов, означающих уже выполненную попытку AI (`generated`, `published`, `error`).
- [ ] Цикл использует этот счётчик до генерации вместо счётчика только опубликованных replies.
- [ ] При `auto_publish=false` тест доказывает, что достигнутый лимит не вызывает AI-провайдер; при `auto_publish=true` существующее ограничение сохраняется.
- [ ] Существующие тесты затронутых модулей проходят без реального browser/AI/БД.
- [ ] Изменение не затрагивает миграции, runtime JSON и admin-панель.
