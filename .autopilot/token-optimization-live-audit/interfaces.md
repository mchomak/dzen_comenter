# Границы, решённые в спецификации

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| Конструктор prompt | состав сообщения модели и бюджет ветки | `build(context) -> str` | способ сохранения последнего фрагмента ветки |
| Репозиторий ответов | счётчик произведённых ответов за окно | `count_ai_attempts_since(since) -> int` | SQL-статусы и границы выборки |
| Цикл ответов | применение почасового лимита до API-вызова | обработку комментариев | публикацию и browser-access |

## Правила проекта

- Python 3.11; полный набор: `/tmp/dzen-commenter-test.3icCmB/bin/pytest`.
- Не проверять изменения реальной авторизацией, браузером Дзена или внешними вызовами.
- Использовать существующие Protocol/инъекционные швы; тесты не поднимают browser, production-БД или AI API.
- Не трогать parser статьи из предыдущего аудита, admin-панель, миграции, Docker и production-конфигурацию.
- Если нужной зависимости нет, вернуть `BLOCKED`, не устанавливать её.

## Тестовые швы

- Поведение сокращения проверяется через `DameoPromptBuilder.build` и `PromptContext`.
- Поведение лимита проверяется через `OrchestratorLoop.run_cycle` и fake repository/provider из существующих тестов.

## Из таска 03 — бюджет ветки

- `DameoPromptBuilder.build(context: PromptContext) -> str` остаётся публичным швом; он передаёт всю ветку до 400 символов и хвост из 400 символов для более длинной.
- Сокращается только `thread_text`; остальные поля `PromptContext` не меняются.

## Из таска 02 — счётчик AI-попыток

- `CommentRepository.count_ai_attempts_since(since: datetime) -> int` считает сохранённые результаты AI со статусами `generated`, `published` и `error`.
- `OrchestratorLoop` использует этот счётчик до вызова AI-провайдера; режим черновиков больше не обходит почасовой лимит.
