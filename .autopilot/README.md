# Как читать эту папку

## Текущая сборка

- Нет активной сборки.

## Завершённые сборки

- `2026-09-10-db-backed-batch-replies` — DB-backed batch-ответы, кэш статьи и отдельные retry публикации; миграция 0009 применена после проверенного backup PostgreSQL.

- `2026-09-05-batch-queue-recovery` — устранено зависание пакетной очереди, недоступные комментарии теперь обрабатываются через ограниченный retry без остановки цикла.

- `dashboard.html` — открылся в начале сборки; можно и двойным кликом. Этапы, прогресс, время и остаток работы обновляются сами.
- `admin-runtime-settings/2026-08-21-brief.md` — исходная задача, после редактирования секретов; не редактируется.
- `admin-runtime-settings/manifest.md` — список требований и их статус.
- `admin-runtime-settings/spec.md` — спецификация.
- `admin-runtime-settings/tickets/` — таски, на которые разбита сборка.

Если сборка прервалась — скажи «продолжи автопилот»: состояние поднимется из `.autopilot/state.js`.
