## Что должно заработать

Большая Studio-лента обрабатывается без повторного обхода уже проверенных групп на каждом шаге прокрутки. Публикационный поиск использует post_url, раскрывает ответы только в карточках нужной публикации и продолжает находить целевую реплику, если она была скрыта.

## Критерии приёмки

- [ ] Сначала написан regression-тест для постепенной подгрузки большой ленты; он падает на повторном сканировании текущей версии.
- [ ] После каждого scroll для раскрытия рассматриваются только новые группы, а целевой поиск с post_url не перечисляет комментарии посторонних публикаций.
- [ ] Скрытый дочерний комментарий в целевой группе находится после раскрытия её ветки; неоднозначные DOM-клики остаются fail-closed.
- [ ] Полная выборка сохраняет все найденные комментарии, синтетические ID и текущие пределы прокрутки/раскрытия.
- [ ] Structured events содержат длительность и счётчики DOM/групп/комментариев/кнопок; доступный JS heap записывается числом, персональные данные не логируются.
- [ ] Узкий Dzen-тестовый файл проходит после реализации.
