# Проверка улучшенного извлечения статей

Дата: 23 августа 2026.

## Изменение

`DzenStudioPage.fetch_article_text()` больше не берёт весь `main` или первый
случайный элемент с `article` в имени класса. Он ждёт Dzen content-root
`[class*="article-render__container"]`, сохраняет заголовок и прямые смысловые
блоки (`p`, `h2`–`h4`, `li`, `blockquote`) и отбрасывает подписи изображений,
встроенные рекомендации и известные рекламные/CTA-блоки.

Если content-root не найден, применяется только семантический `<article>`.
Широкий fallback `main` удалён: лучше не передать контекст, чем передать chrome
всей страницы.

## Независимая live-проверка

Пять других `/a/` URL выбраны read-only из production PostgreSQL; они не
пересекаются с первоначальной выборкой. Каждый URL получен старой и новой
версией метода в отдельной копии production Chromium-профиля.

«Рекомендую эти статьи».

browser profile, затем она удалена.
