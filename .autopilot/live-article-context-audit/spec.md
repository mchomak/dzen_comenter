# Спецификация: live-аудит текста статей Дзена

## Задача

Получить реальные ссылки на текстовые статьи из production БД, локально извлечь текст точно существующим методом бота, сохранить результаты и посчитать долю не относящегося к статье текста.

## Решение

После безопасной key/certificate-аутентификации выполнить один read-only запрос к PostgreSQL для небольшого набора `https://dzen.ru/a/...` URL. Локально, в изолированном Playwright-контексте, вызвать `DzenStudioPage.fetch_article_text()` для каждого URL. Сохранить результат каждого вызова в отдельный `.txt`, затем классифицировать строки как article body или page chrome и вычислить проценты по символам и строкам.

## Пользовательские истории

| # | Метка | История | Приёмка |
|---|-------|---------|---------|
| 1 | R01 | Как аудитор, я беру несколько реальных URL статей из production БД, чтобы выборка соответствовала работе бота. | Read-only выборка содержит только `/a/...` URL; воркер не запускается и БД не изменяется. |
| 2 | R02 | Как аудитор, я получаю текст каждой статьи тем же методом, что использует бот. | Для каждого URL выполнен `DzenStudioPage.fetch_article_text()`; HTTP-парсер не используется. |
| 3 | R03 | Как владелец сервиса, я могу прочитать исходный извлечённый текст. | Каждый результат сохранён в `samples/article-NN.txt`; файл содержит selector, длину и полученный текст. |
| 4 | R04 | Как владелец сервиса, я знаю объём лишнего текста. | Отчёт содержит raw chars, article-body chars, noise chars и долю шума по каждой выборке и суммарно. |

## Решения по реализации

- Доступ к production — только уже настроенный SSH key/certificate; пароль из переписки не используется.
- В PostgreSQL запрашиваются только URL, не данные комментариев; выборка не должна изменять состояние.
- Точный extractor — `DzenStudioPage.fetch_article_text(post_url)`. Для каждой записи фиксируется первый selector, сработавший в порядке `article`, `main`, `[class*="article"]`.
- `samples/article-NN.txt` хранит извлечённый текст и метаданные измерения. URL в отчёте маскируются; сами тексты сохраняются локально, как запросил пользователь, и не отправляются внешнему сервису.
- Шум считается по фактически извлечённому тексту: служебные строки, блоки рекламы, рекомендаций, навигации, подписки и комментариев отделяются от смысловых заголовков/абзацев. Каждая классификация сопровождается коротким основанием; неуверенные строки помечаются отдельно, не засчитываются молча.

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| production URL reader | read-only выборкой `post_url` | набор URL статей | учётные данные и SQL-подключение |
| `DzenStudioPage` | браузерным извлечением | `fetch_article_text(post_url) -> str | None` | Playwright-вкладку и кэш |
| audit runner | сохранением и расчётом метрик | `.txt`-выборки и отчёт | URL и внутренние детали сервера |
