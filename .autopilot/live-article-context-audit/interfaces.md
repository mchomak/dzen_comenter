# Границы live-аудита

- Источник URL — read-only PostgreSQL production; только текстовые `/a/...` ссылки, без чтения или записи пользовательских комментариев.
- Извлечение — локальный `DzenStudioPage.fetch_article_text(post_url)` без запуска воркера и без вызова GigaChat.
- Артефакты — `samples/*.txt` с полученным текстом и `report.md` с посчитанной долей шума; URL и секреты не публикуются.
- Внешний доступ — только уже настроенная ключевая/сертификатная аутентификация. Пароль из переписки не используется.
