## Что должно заработать

Основная страница админки показывает 200 последних строк ленты. У каждой записи с сохранённым безопасным URL поста видна подчёркнутая кликабельная ссылка. История `/comments` продолжает показывать все строки и ссылки.

## Из брифа, дословно

> «чтобы ссылка на пост всегда отображалась в админке»
> «и была кликабельной (то есть с гиперссылкой)»
> «проставь ссылки для последних 200 комментариев»
> «по идее ссылки на посты должны быть и так в БД, нужно только их выводить.»

## Разделы спецификации

Пользовательские истории 1–4, Решения по реализации, Допущения полного режима.

## Критерии приёмки

- [x] Главная запрашивает и показывает до 200 последних строк ленты, отсортированных от новых к старым; текст счётчика сообщает лимит 200.
- [x] При наличии 200 записей каждая запись с допустимым `post_url` содержит видимую HTML-гиперссылку на сохранённый URL.
- [x] В основной ленте ссылка в заголовке поста постоянно подчёркнута; ссылка открывается безопасно в новой вкладке.
- [x] История по-прежнему не ограничена 200 строками и для сохранённых допустимых URL выводит кликабельные ссылки.
- [x] Regression test на HTTP-страницу создаёт больше 200 строк, проверяет размер и порядок основной ленты и ссылки всех первых 200 записей; его запускают до production-правок и подтверждают ожидаемое падение.
