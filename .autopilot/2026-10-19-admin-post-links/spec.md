# Спецификация: ссылки на посты в админке

## Задача

В основной ленте админки должны быть видны комментарии и кликабельные ссылки на публикации, под которыми они оставлены. Нужны последние 200 комментариев.

## Решение

Основная страница показывает до 200 последних комментариев. У каждой записи с сохранённым URL публикации заголовок поста выглядит как ссылка, а столбец «Пост» также содержит прямую ссылку. История комментариев продолжает показывать все найденные записи.

## Пользовательские истории

| # | Метка | История | Приёмка |
|---|-------|---------|---------|
| 1 | R01 | Как администратор, я вижу исходную публикацию у комментария | Каждая запись в админке выводит кликабельную ссылку на исходный пост из `comments.post_url`. На сервере 2026-10-19 проверена вся production-таблица: 7 585 строк, у всех 7 585 допустимый URL; live HTML полной истории также не содержал пропусков. Главная после изменения показывает первые 200 записей основной ленты, история `/comments` — полный архив. |
| 2 | R02 | Как администратор, я могу открыть публикацию по ссылке | На обеих страницах ссылка — HTML-гиперссылка на HTTPS-адрес поста Дзена и открывается в новой вкладке с `rel="noopener noreferrer"` |
| 3 | R03 | Как администратор, я вижу ссылки у последних 200 комментариев | «Последние 200» — это первые 200 строк главной админки `/`, выбранных её действующими фильтром аккаунта бота и порядком по `fetched_at`, `id` по убыванию. Это сохраняет существующую семантику главного списка, для которого запрошено изменение; история `/comments` остаётся полной выборкой. |
| 4 | R04 | Как администратор, я получаю ссылку из уже сохранённых данных | Используется только `comments.post_url`; схема БД и production-данные не переписываются. Проверка на сервере 2026-10-19 была read-only и проверила все строки таблицы `comments`: 7 585 строк, 7 585 непустых `post_url`, 7 585 URL, прошедших ту же проверку Dzen-домена и пути, что использует админка. В целевой выборке последних 200 также 200/200 допустимых URL. Текущий HTML истории вернул HTTP 200 и 0 заглушек «Ссылка отсутствует». |
| 5 | R05 | Как владелец проекта, я получаю сохранённое и отправленное изменение | Исправление оформлено коммитом и отправлено в настроенный Git remote |
| 6 | R06 | Как пользователь админки, я получаю изменение на сервере | Собран и перезапущен только сервис `admin`; после запуска проверены здоровье сервиса и HTML основной ленты с 200 ссылками |

## Решения по реализации

- Главная и история используют существующий FastAPI/Jinja-путь и общий шаблон ленты; главная получает лимит 200, история остаётся без лимита.
- URL берётся из `comments.post_url` и проходит существующую проверку безопасного домена и путей Дзена. В текущей production-таблице все сохранённые значения проходят эту проверку. Адрес нельзя угадывать из `publications.url`, потому что эта запись хранит URL входящей ленты комментариев. Развёртывание считается проверенным только когда HTML основной ленты содержит 200 строк с 200 ссылками.
- Название поста в диалоге получает постоянно видимое подчёркивание, чтобы его было проще распознать как ссылку.
- Изменение ограничивает количеством 200 только главную `/`, оставляя её существующий фильтр аккаунта бота и сортировку `fetched_at`, `id` по убыванию. Это выбор целевой страницы: исходная формулировка просит показать ссылки «в админке», а главная является основным списком; правила отбора записей не меняются.
- По дополнительному указанию пользователя Obsidian для этого проекта и этапа не используется; рабочие артефакты Autopilot остаются в репозитории.
- Для исправления достаточно админского сервиса. Миграции, перезапуск воркера и реальный вход в Дзен не нужны.

## Допущения полного режима

- ASSUMPTION — «последние 200 комментариев» означает 200 последних записей главной админки по её существующим правилам, включая исключение комментариев аккаунта бота. Режим `full` делегирует этот выбор; правило отбора сохранено и точно описано выше.
- ASSUMPTION — разовая запись в БД не нужна: проверка всей production-таблицы подтверждает допустимый `post_url` у всех существующих записей, а задача просит выводить уже сохранённые адреса.

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `admin.queries` | чтением ленты и безопасной нормализацией `post_url` | `fetch_feed(engine, limit, ...) -> list[FeedRow]` | SQL выборку и правила допустимых URL |
| `admin.app` и шаблон ленты | лимитом основной страницы и ссылками в UI | HTTP-маршруты `/` и `/comments` | сбор контекста шаблона и разметку строк |

Шов для тестов: создание приложения с внедрённым SQLAlchemy engine и проверка HTML через существующий FastAPI `TestClient`; внешние сервисы не вызываются.

## Вне рамок

| Требование | Почему не сейчас |
|---|---|
| Массовая запись или реконструкция URL в БД — R04 | Production-проверка подтвердила наличие допустимого `post_url` у последних 200 записей; пользователю нужна его выдача в UI |
| Повторный сбор данных из Дзена — R04 | Ссылки уже находятся в БД; реальные запросы к Дзenu запрещены правилами проекта |
