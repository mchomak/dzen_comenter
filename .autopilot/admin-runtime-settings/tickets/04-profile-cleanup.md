# 04 — Гарантированная очистка профиля при смене аккаунта Дзена

**Требования:** R07
**Blocked by:** 03
**Зона:** `dzen_commenter/browser/`
**Волна:** 4
**Status:** ready

## Что должно заработать

Смена аккаунта не продолжает работу со старым browser profile, если его нельзя удалить. В этом случае операция завершается ошибкой до запуска нового браузера и админка получает безопасный неуспешный результат.

## Из брифа, дословно

> «бот удалит текущую сессию, откроет сайт заново (так его точно разлогинит из аккаунта) и запустит по новой вход в аккаунт, но уже с новыми данными.»

## Разделы спецификации

История 9, Решение 6, Граница browser session.

## Критерии приёмки

- [ ] Неудачное удаление собственного profile не маскируется: чистая сессия не запускается, а вызов возвращает безопасный failure без секрета.
- [ ] Успешный путь очистки и входа не меняется.
- [ ] Тест смены аккаунта, socket login path и внешняя авторизация Дзена не запускаются по условию заказчика; разрешена только безопасная проверка импорта/компиляции.
